# 職場霸凌防治導覽

依勞動部《職場霸凌防治措施指導手冊》（115年6月）整理的非官方導覽網站。選擇僱用勞工人數後，各頁的「法定／得參照」標示、待辦清單與期限會跟著改變。

網站：https://samuel003009.github.io/workplace-bullying-guide/

本站不是政府網站，不受理申訴，也不提供個案法律意見；內容以手冊與法規為準。

## 頁面

| 頁面 | 內容 |
| --- | --- |
| 首頁 | 規模提問、宣導影片、處理流程六站、關鍵期限、依角色進入 |
| 認識職場霸凌 | 法定定義六要件、認定原則、四類樣態 |
| 規模義務檢核 | 義務矩陣、所選規模的待辦清單、人數算法 |
| 事前防治 | 五項事前措施、分眾教育訓練 |
| 知悉後處置 | 因申訴知悉、非因申訴知悉兩條路徑 |
| 申訴與調查 | 紀錄、受理、登錄、協調、調查、決定 |
| 申復與後續 | 申復流程、重新調查；懲處、保護、追蹤與紀錄 |
| 期限試算與書表範本 | 期限試算；手冊附錄 1–14 範本 |
| 協助資源與常見問題 | 手冊附錄 15–16 資源；常見問題；內容對照 |

網站的規劃、設計與「手冊章節對網站頁面」的對照，見 [docs/PRD.md](docs/PRD.md)。
