# 職場霸凌防治導覽網站 PRD

> 本文件由規劃階段的 PRD 匯出，記錄網站的規劃、設計、頁面內容、技術規格與內容對照。

本站把勞動部《職場霸凌防治措施指導手冊》（115年6月，本文與附錄共 58 頁）改寫成一個可依事業單位規模、角色與處理步驟查詢的非官方導覽網站，第一版為 13 頁的靜態單頁應用，已依本文件建置完成。

第一版為單檔網站（約 114KB，13 頁）；本儲存庫是第二版的 Next.js 專案，見文末「Next.js 版（9 頁）」。全站搜尋與規範產生器列在後續版本。

## 網站規劃

網站名稱為「職場霸凌防治導覽」，定位是依手冊整理的非官方導覽站：不取代手冊與法規、不受理申訴、不提供個案法律意見。核心承諾是讓雇主在 5 分鐘內知道「我這個規模要做什麼、什麼時候要做完」。

### 目標與成功指標

| 目標 | 衡量方式 | 建議目標值 |
| --- | --- | --- |
| 快速找到自己規模的法定義務 | 從首頁到義務清單的點擊數 | 2 次以內 |
| 所有法定期限可由日期推算 | 期限試算涵蓋的期限項目數 | 手冊所列期限 100% |

| 內容不失真 | 人數門檻、期限、比例與手冊逐項比對的差異數 | 0 |

### 範圍外

- 不受理或轉送申訴，不蒐集任何個人資料，無登入與後台。
- 不判斷個案是否成立霸凌，不提供法律意見。
- 不使用勞動部的名稱、標誌或版型作為網站識別；每頁標示非官方並指向原始手冊。

## UI/UX 設計

整站是一份「可以操作的法遵手冊」：左側導覽照處理順序排列，頂部的規模切換器決定每一頁哪些內容標為法定、哪些標為得參照。

### 設計原則

1. 先給答案，再給條文。每頁第一段直接說「誰、要做什麼、多久內」，條文與頁碼放在區塊尾端的來源標籤。
2. 規模是全站的主軸。使用者只選一次規模，全站 13 頁同步改變，不必每頁重選。
3. 法定與得參照永遠分得出來。沿用手冊表 1 的記號：法定是實心勾，得參照是空心圈，再加文字，不只靠顏色。
4. 語氣冷靜。主題涉及受害經驗，不用警示紅底、驚嘆號或誇張插圖。
5. 可查證。任何數字都能在同一畫面看到它出自手冊第幾頁、準則第幾條。

### 無障礙與文案

- 所有互動元件有可見的鍵盤焦點；流程與徽章都有文字，不依賴顏色或圖示。
- 動畫僅限頁面切換的淡入，系統設定「減少動態」時關閉。
- 用語跟手冊一致：申訴人、被申訴人、申訴處理單位、調查小組、申復。不自創名詞。
- 每頁頁尾固定一句：本站為依勞動部手冊整理的非官方導覽，內容以手冊與法規為準。

### 首頁文案

- 主標：職場霸凌防治，你的公司該做哪些事
- 副標：依勞動部《職場霸凌防治措施指導手冊》整理。選擇僱用人數，就能看到法定義務、處理步驟與每一個期限。
- 規模提問：事業單位僱用幾位勞工？
- 聲明：非官方網站，不受理申訴。內容以手冊與法規為準。

### 文案規則

- 義務用「應」，建議用「宜」或「建議」，與手冊的用字強度一致。
- 期限一律寫出起算點，例如「接獲申訴之日起 10 個工作日內」。
- 手冊的建議作法標示「建議作法」，不與法定義務混排。

## 技術規格

第一版是單一 HTML 檔的靜態網站，沒有後端、不蒐集資料，內容與試算規則都寫在前端的資料物件裡。

### 本版架構

| 項目 | 規格 |
| --- | --- |
| 形式 | 單一 HTML 檔，樣式與程式內嵌；不需建置流程 |
| 路由 | 以網址錨點切換 13 頁，例如 `#deadline`；可直接分享到某一頁 |
| 狀態 | 僅有「所選規模」與試算輸入；規模存在瀏覽器 localStorage，讀寫失敗時照常運作 |
| 外部資源 | 僅 Google Fonts 三套字型；無第三方追蹤、無 Cookie |
| 資料 | 無後端、無表單送出、不傳送任何輸入內容 |
| 瀏覽器 | Chrome、Edge、Safari、Firefox 近兩個主要版本；手機寬度 360px 起 |
| 主題 | 淺色與深色，跟隨系統設定 |

| 作成申復決定 | 申復審議會議召開日 | 30 日內，再行調查得展延 30 日 | 30 人以上 | §23 |
| 通知申復結果並登錄 | 申復決定日 | 10 個工作日內 | 30 人以上 | §23 |
| 重新調查作成決定 | 主管機關或勞動檢查機構要求之日 | 2 個月內 | 全部 | §24 |

計算方式有三點假設，網站在試算頁明示：

- 工作日以週一至週五計，使用者可加入國定假日與補班日；網站不內建行事曆。
- 條文寫「之日起」者當日算入，寫「翌日起」者次日算入。這是較早到期的保守算法，實際起算以主管機關解釋為準。
- 以月計算者，到期日為起算日在到期月份相當日的前一日；該月無相當日時為月底。期限末日遇假日不自動順延。
